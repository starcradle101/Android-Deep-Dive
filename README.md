# Android-Deep-Dive

이 리포지토리는 **Android 플랫폼과 프레임워크에 대한 심층적인 학습 내용을 '나만의 언어'로 정리**하고, **실무에 바로 적용 가능한 유용한 템플릿 코드**를 보관하는 지식 베이스입니다.

## 🎯 학습 목표

1.  Android 핵심 컴포넌트의 생명 주기(Lifecycle) 및 동작 원리 심층 이해.
2.  Jetpack 라이브러리(Compose, Architecture Components) 및 개발 트렌드 정리.
3.  면접 및 과제 전형, 프로젝트에서 즉시 활용 가능한 고품질 코드 템플릿 확보.

## 📚 목차 (Contents)

| 폴더/파일명               | 주요 내용                                                                                                    |
| :------------------------ | :----------------------------------------------------------------------------------------------------------- |
| **`01_Architecture/`**    | MVVM, MVI, Clean Architecture 등 **설계 패턴**, Jetpack Navigation, Hilt/Koin 등 의존성 주입(DI) 관련 정리.  |
| **`02_Core_Components/`** | Activity, Fragment, Service, Broadcast Receiver, Content Provider 등 **안드로이드 핵심 컴포넌트** 심층 분석. |
| **`03_UI_and_UX/`**       | Jetpack Compose와 전통적인 View 시스템(Custom View, Layout) 및 애니메이션 관련 정리.                         |
| **`04_Testing/`**         | Unit Test, Integration Test, UI Test(Espresso/Compose Test) 작성 방법 및 원칙 정리.                          |
| **`A_Templates/`**        | 개인 및 그룹 프로젝트에서 유용하게 사용 가능한 **재사용 가능한 코드 템플릿 모음**.                           |

## 🛠 유틸리티 및 템플릿 (A_Templates)

실제 개발 과정의 효율성을 높이기 위해 구조화된 템플릿 코드를 모아두고 있습니다.

> **활용 방법**: 이 폴더의 코드를 복사하여 새로운 프로젝트의 기반으로 즉시 사용할 수 있습니다.
